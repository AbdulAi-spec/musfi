# ❤️ Happy Birthday Dr. Musfi | With Love from Abdul Rehman

An interactive, luxury-styled birthday celebration and love quiz designed exclusively for **Dr. Musfi**, an Eye Doctor (Ophthalmologist), from her future husband, **Abdul Rehman**.

---

- **🩺 Ophthalmology & Vision Theme**:
  - Custom Snellen Eye Chart (*"EYES ON YOU DR. MUSFI - ABDUL REHMAN"*).
  - Clinical love prescriptions and ophthalmic pupillary dilation diagnoses.
- **📸 14 Interactive Story Chapters**:
  - Milestones: Graduation, the first bus date, the first home visit, and future bride in red & gajras.
  - Adrenaline & Thrill: Fast bike rides, cold wind hugs, and the sudden brake rule.
  - Spicy & Dark Romance: The collarbone "sweet food" mark and the blindfold fantasy.
  - Fun & Playful: Chota Don mafia filter, the iconic Tang meme, and chocolate ice cream cravings.

  - An interactive, animated soundwave player that plays Dr. Musfi's real voice whisper (*"Abdul Rehman..."*).
- **🎂 Birthday Cake & Candle**:
  - A celebratory 2-tier cake with an interactive candle flame she can tap to blow out with confetti explosions!
- **💌 Heartfelt Love Letter**:
  - A private, emotional love letter sealed from Abdul Rehman.
- **📱 100% Mobile Optimized**:
  - Built with responsive design for iPhone Safari and Android Chrome with safe-area notch awareness and instant touch feedback.

## 🚀 How to Run Locally

You can open `index.html` directly in any web browser, or run a local server:

```bash
# Python
python -m http.server 8080
```

Then visit `http://localhost:8080` in your browser.

---

## 🌐 Deploy to GitHub Pages for Mobile Access

1. Push this repository to GitHub.
2. In your GitHub repository, go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**.
5. Within 1-2 minutes, GitHub will provide a live link (e.g., `https://<your-username>.github.io/<repo-name>/`) that Dr. Musfi can open directly on her mobile phone anywhere!
